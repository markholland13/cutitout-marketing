Which file have you got?

Ready DXF, STEP and STP files can go straight to quoting. Use File Workshop for other formats or to review drawing repairs.

2D CUTTING DRAWING

DXF / DWG

Full-size 2D geometry in millimetres. Keep only the cutting paths; remove dimensions and drawing borders.

VECTOR ARTWORK

SVG / PDF

Real vector paths. Convert intended cut text to outlines. PDF must be one page, with no embedded images.

BLACK & WHITE ARTWORK

JPG / PNG

A sharp, solid black shape on white. Check the traced detail and set the finished size yourself.

SHEET-METAL MODEL

STEP / STP

One sheet-metal body of consistent thickness. Suitable models are unfolded first. The editor then works on the flat drawing, not the original 3D model.

02 / JPG & PNG: KEEP IT BLACK AND WHITE

A silhouette.
Not a photograph.

Export flat, front-on artwork from your software.
No shading, shadows or perspective.

Black stays.
White is cut away.

File Workshop traces the boundaries between black and white. Every unwanted mark can become another outline.

Black = material to keepWhite inside = holes & cutouts

Show the whole part with a little white space around it. Make small holes and gaps clear enough to see.

For JPG and PNG, use a filled silhouette. A thin line drawing can trace both sides of each line. Export vector paths as DXF or SVG when you have them.

BEFORE EXPORTING FROM YOUR SOFTWARE

Send the shape.
Leave the page behind.

  • Export just the part. Remove backgrounds, borders, dimensions, logos and notes you do not want cut.
  • For images: black on white. Use a filled, front-on shape with crisp edges. Check that every hole remains visible.
  • For vectors: actual paths. Close outlines, remove duplicates, and convert text intended for cutting to curves or outlines.
  • Check scale after export. Use 1:1 in millimetres for CAD. Images need a real finished dimension set in File Workshop.

PDF: WHAT’S INSIDE MATTERS

Saving as PDF
doesn’t make it a drawing.

Export one page of real vector outlines from your design software.

Multi-page PDFs and PDFs containing embedded images are rejected, even if some vector lines are present.

SAME IMAGE. DIFFERENT FINISHED SIZE.

Pixels aren’t millimetres.

Enter a known width or height. Keep proportions locked so circles stay round. Unlocking proportions stretches the part and changes its features.

03 / ALREADY HAVE A DXF?

See the issue.
Review the fix.

File Workshop can help repair cutting geometry.
Compare every proposed change with your original.

Small gapsDouble cutsDrawing clutterSegmented curvesLoose centres

Close a small gap.

The editor can join suitable small, local gaps. Review the new segment before accepting it. Large gaps need a design decision; an intentional slit should not be closed automatically.

Cut each edge once.

Verified duplicate paths can be removed while keeping the intended edge. Duplicate cuts can add unnecessary cutting length and cost. Intersecting parts need a closer look.

Replay shows the same outside edge twice on the left and once on the right.

Keep only the part.

Hide drawing-aid layers or remove unwanted marks. If the file contains several parts or views, choose the part you actually want. Keep every intended hole.

Restore a real curve.

File Workshop can suggest restoring suitable segmented circles and arcs. Compare Original and Prepared before applying the change; some faceted shapes are intentional.

Keep inner details attached.

Why bridges matter ↗

Review suggested bridges only where a centre should stay attached. Bridges change your design; their placement and width must suit the material and use. Leave intended holes open. Blue highlights identify uncut metal; dimensions are illustrative.

SOME ISSUES NEED YOUR DECISION

A repair still needs a review.

  • Missing detail or unclear artwork: return to the original design. File Workshop cannot know what was intended.
  • Material and size limits: a clean drawing still needs to meet the cutting requirements.
  • A STEP file that cannot unfold: correct the original sheet-metal model. The editor repairs the prepared flat drawing, not the 3D source.
