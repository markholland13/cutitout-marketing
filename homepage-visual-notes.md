# Homepage visual refresh

Local homepage: `/`. No deployment performed.

The homepage now uses the same Services/Materials foundation, navy and pale-blue palette, typography, shared header and complete footer. It opens with “You design it. We’ll Cut It Out.”, a clear quote CTA and the original workshop cutting video, followed by three ordering steps, the existing Blender manufacturing film, four material cards, a before/after design-guide example, textured coating and the family workshop.

The duplicated full-page background video, rotating showcase and reveal-on-scroll handlers were removed. At the user's request, one copy of the original workshop video is restored in the hero with native playback controls. `static/js/home-video.js` starts it muted when visible, skips automatic playback for reduced-motion/data-saving preferences, and pauses it when offscreen or the tab is hidden. Blocked autoplay leaves the native play button available. The existing Blender film's content, render frames and JavaScript remain unchanged, including the skip control, final quote screen and reduced-motion/data-saving fallbacks. The film's previously inline base styles now live in `static/css/manufacturing-film.css`, so they no longer depend on the retired homepage layout. A no-JavaScript still fallback is included for the Blender film; the workshop video retains native manual controls.

`static/css/home-visual.css` contains the homepage layout. No external animation dependency was added. Existing metadata and analytics are preserved. Cross-page links retain the correct absolute public URLs. The Materials cards reflect the confirmed stock range, including 1 mm aluminium. Detailed limits are left to the current guide rather than repeating the old homepage's blanket size limit.

Verification: all site tests pass, including homepage structure, current routes, image references, all 516 dynamic animation frames, film skip/reverse/end-card logic and reduced-motion fallback. Responsive DOM checks passed at 320, 390, 768 and 1280 px with no horizontal document overflow. Browser checks verified film frame loading and progression, the skip control focusing the Materials section, and normal-window hero/material visuals. No browser errors reported. Viewport override reset after checks.
